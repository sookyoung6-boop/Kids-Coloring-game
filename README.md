# Coloring Game

A static browser coloring game built with plain HTML, CSS, and JavaScript.

## Play locally

Open `index.html` directly in a browser. No server, build step, or package install is required.

## Publish on GitHub Pages

1. Upload this folder to a GitHub repository.
2. In the repository, open `Settings` > `Pages`.
3. Set the source to `Deploy from a branch`.
4. Choose the `main` branch and `/root`.
5. Save, then open the GitHub Pages URL once the deployment finishes.

## Files to keep

- `index.html`
- `style.css`
- `game.js`
- `assets/background-fast.jpg`
- `assets/selection-background-fast.jpg`
- `assets/pages-fast/`
- the tool/button PNG files in `assets/`
- `.nojekyll`

The original full-resolution PNG files can stay local as source artwork. The game uses the optimized `fast` assets for faster loading on phones and GitHub Pages.
